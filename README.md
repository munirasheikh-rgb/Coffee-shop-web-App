# Coffee Shop Web Application
The Coffee Shop Web Application, is a single page application(SPA) 
built with React that allows users to browse coffee products,
search for items,edit and remove coffee products.
The application also includes an Admin portal for managing products
## Features
- User authentication and login
- Browse coffee products
- Search for products
- Remove items
- Update item prices
- Admin portal for product management
- Client-side routing with React Router
- Data persistence using JSON
## Technologies used 🛠️
- React.js
- Javasccript
- HTML5
- CSS3
- Bootstrap
- JSON Server
- REST APIs
- Git&Github
## Installation
Clone the repository
```bash
git clone https://github.com/munirasheikh-rgb/Coffee-shop-web-App.git
```
Navigate to the project directory
```bash
cd Coffee-Shop-Web-App
```
Install dependencies
```bash
npm install
```
Start the development Server
```bash
npm run dev
```
Start JSON Server
```bash
npx json-server watch db.json --port 3001
```
